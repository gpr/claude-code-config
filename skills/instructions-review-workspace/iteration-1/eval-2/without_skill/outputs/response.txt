## 2. Conflicts and redundancies

**Conflict — L326 loses to `~/.claude/CLAUDE.md`.** L326 tells Claude to "verify it's appropriate, then use `ask_incident`" for a status change. `~/.claude/CLAUDE.md` (*Philosophy*) says "**Ask first on big decisions** — ask before … external API mutations." Resolving an incident is an external mutation visible to the responder team. **CLAUDE.md wins**: confirm with the user, don't self-certify. Compounding this, L291 calls "change status to resolved" *"already self-contained and doesn't need expansion"*, which reads as licence to fire it off. The rewrite replaces both with a single "Mutations need the user's word" section.

**Conflict — L344–351 loses to L50–56.** L50–56 mandates `AskUserQuestion` for selections; L344–351 hand-rolls a fake button box. **`AskUserQuestion` wins** — it's a real interaction; the box is decoration.

**Redundant against the `incident_io` tool schemas** (these load with the tools, so the skill pays twice):
- L80–83 duplicates `incident_show`'s description: *"For investigation or root cause analysis, request include: ["investigation", "postmortem"] — the default response without these only gives you the basic metadata."*
- L121–133 (13 lines on `session_id`) duplicates `ask_incident`: *"Returns a session_id: reuse it in follow-up calls so the agent keeps context and can act on previous answers."*

- L44 and L144 duplicate `escalations_list`: *"Use this to find which incident to investigate."*
- L181–182, L188–191, L211–214 duplicate `incident_message`: *"Requires the user's explicit approval… Never post your own findings, conclusions, or status updates unprompted… Use --message for a brief summary (1-2 sentences) and --thread-message for detailed explanations."*
- L97 duplicates `escalation_list`: *"see config://organisation for IDs"*.

**Redundant against `~/.claude/CLAUDE.md`:** nothing beyond the L326 conflict — the two files barely overlap in subject.

**Not redundant, kept intact:** the hedging/attribution rules (L196–210) and the confirmed-vs-investigating example pair (L233–250). No tool schema or always-loaded source covers "preserve the user's level of certainty" or "prefer 'the issue' over 'root cause'". This is the highest-value content in the file.
